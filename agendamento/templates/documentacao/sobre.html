📋 Sobre o Sistema de Agendamento

🎯 O que é este sistema?

Este sistema foi desenvolvido para gerenciar o agendamento do salão de forma organizada e eficiente.

✨ Funcionalidades principais:
  • 👥 Agendamento simplificado: Escolha mês, dia e horário com poucos cliques
  • 🔒 Sistema de permissões: Diferentes níveis de acesso (usuário, admin, superadmin)
  • 🚫 Bloqueio de horários: Para reuniões, eventos ou manutenção
  • 📱 Interface responsiva: Acesse de qualquer dispositivo
  • 🔔 Notificações: Confirmação instantânea dos agendamentos

🧪 Testes e Qualidade

O sistema passou por rigorosos testes automatizados para garantir sua estabilidade:

✅ Testes realizados:
  • Testes de autenticação (login/cadastro)
  • Testes de agendamento (criação/edição/cancelamento)
  • Testes de permissões (acesso controlado)
  • Testes de bloqueios de horário
  • Testes de integração (fluxo completo)
📊 Métricas de qualidade:
  • 100% dos testes passando
  • 22 testes automatizados
  • Cobertura de todas funcionalidades principais
  • Validação de regras de negócio

👥 Para diferentes tipos de usuários

👤 Usuário Comum
  • Agendar horários
  • Ver seus agendamentos
  • Editar/cancelar agendamentos
🛡️ Admin da Congregação
  • Todas funções do usuário
  • Gerenciar usuários
  • Criar bloqueios de horário
  • Ver todos agendamentos da congregação
👑 SuperAdmin
  • Todas funções do admin
  • Acesso a todas congregações
  • Gerenciar todos os bloqueios
  • Controle total do sistema

❓ Como usar

Passo a passo para agendar:
  1. Faça login na sua conta caso não tenha uma conta, cadastre uma no botão abaixo ou no barra de navegação
  2. Clique em "Agendar" no menu
  3. Escolha o mês desejado
  4. Selecione o dia
  5. Escolha um horário disponível
  6. Confirme o agendamento
📞 Suporte

Em caso de dúvidas ou problemas, entre em contato com o administrador do sistema.
